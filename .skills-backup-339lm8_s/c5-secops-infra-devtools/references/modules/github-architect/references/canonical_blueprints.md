# Canonical Repository Blueprints (C5-REAL High-Exergy Standards)

This document specifies the exact structural blueprints, documentation hierarchy, CI/CD pipelines, and release engineering configurations for the 7 canonical repository archetypes.

## Archetype 1: Bare-Metal Systems & CLI Tools (Rust / Go / C / Zig)

### Characteristics
- Single static binary output (`musl` on Linux, native ARM64/x86_64 on macOS, PE on Windows).
- Zero runtime dependencies.
- Sub-50ms cold startup time.

### Directory Layout
```text
.
├── .github/
│   ├── workflows/
│   │   ├── ci.yml                # Multi-platform test & lint matrix
│   │   ├── release.yml           # Cross-compilation & artifact signing (SLSA 3)
│   │   └── audit.yml             # Dependency vulnerability scanning
│   ├── ISSUE_TEMPLATE/
│   │   ├── bug_report.yml
│   │   └── feature_request.yml
│   └── pull_request_template.md
├── docs/
│   ├── assets/demo.svg           # VHS / Asciinema SVG terminal recording
│   └── ARCHITECTURE.md
├── src/                          # Application source code
├── tests/                        # Integration and end-to-end tests
├── Cargo.toml / go.mod
├── LICENSE
├── Makefile / Taskfile.yml
├── README.md
└── SECURITY.md
```

## Archetype 2: Software Development Kit / Library (TypeScript / Python / Go)

### Characteristics
- Strictly typed interfaces (TypeScript `.d.ts`, Python `.pyi` / `py.typed`).
- Zero unneeded transitive dependencies.
- Dual ESM / CJS or pure modern ESM packaging.
- Automated API reference generation.

### Directory Layout
```text
.
├── .github/
│   └── workflows/
│       ├── ci.yml                # Matrix test across language versions
│       └── publish.yml           # OIDC Trusted Publishing (PyPI / npm / crates)
├── docs/
│   ├── api/                      # Autogenerated TypeDoc / Sphinx docs
│   └── MIGRATION.md
├── src/
├── tests/
├── package.json / pyproject.toml
├── README.md
├── CHANGELOG.md
└── LICENSE
```

### Trusted Publishing CI Pattern (GitHub Actions OIDC)
```yaml
name: Publish Package
on:
  release:
    types: [published]

permissions:
  id-token: write  # Mandatory for OIDC exchange
  contents: read

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683 # Pin commit SHA
      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - name: Build sdist and wheel
        run: pip install build && python -m build
      - name: Publish to PyPI
        uses: pypa/gh-action-pypi-publish@release/v1
```

## Archetype 3: Infrastructure Appliance / Service (Docker / K8s / Go)

### Characteristics
- Hermetic container builds with minimal attack surface (`scratch` or `distroless`).
- OCI container images signed with Sigstore Cosign.
- SBOM published with release artifacts.
- Trivy / Grype vulnerability scans in CI fail-closed.

### Key Workflows
- Docker Buildx with multi-platform caching (`cache-to=type=gha,mode=max`).
- GitHub Container Registry (GHCR) publishing.

## Archetype 4: AI Engine / Inference Runtime (C++ / CUDA / Metal / Rust)

### Characteristics
- Hardware acceleration matrix (Metal on Apple Silicon, CUDA, ROCm, CPU AVX-512).
- Quantization support matrix (GGUF, FP16, INT8, INT4).
- Deterministic benchmark tables with token/sec latency graphs.
- Direct links to verified HuggingFace weights with SHA-256 hashes.

---

## Archetype 5: Scientific Research & Academic Paper Artifact

### Characteristics
- Complete bit-by-bit computational reproducibility.
- Deterministic random seeds specified in every script.
- Single command to regenerate all manuscript figures (`make figures`).
- Persistent DOI badge (Zenodo / OpenTimestamps).
- Clear attribution, bibtex citation block, and software license matching academic open science norms.

---

## Archetype 6: Monorepo Platform (TypeScript / Rust / Python)

### Characteristics
- Shared workspaces (Cargo Workspaces, pnpm workspaces, uv workspaces).
- Incremental CI: only test and build affected packages (Turborepo, Nx, or git diff filters).
- Changesets / Release-Please for automated semantic versioning and changelogs per package.

---

## Archetype 7: Specification, RFC & Knowledge Corpus

### Characteristics
- High typography standards (VitePress, Astro, mdBook or clean GitHub Pages).
- Automated link integrity checks (`lychee`).
- Prose style and spelling linting (`vale`).
- Semantic versioning of the specification itself.

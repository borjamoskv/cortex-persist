# Invariante de Enrutamiento de Modelos y Regímenes Térmicos (C5-REAL)

## 1. Principio Termodinámico Rector
Queda estrictamente prohibido asignar tareas de falsación popperiana, validación formal o auditoría fáctica a modelos optimizados exclusivamente para latencia/throughput (familia Flash) sin supervisión de un oráculo pesado o verificación física de silicio.

## 2. Matriz Canónica de Selección de Modelos (La Frontera de Alta Exergía)

| Dominio Operativo / Tarea | Modelo Primario | Régimen Térmico | Justificación Termodinámica |
| :--- | :--- | :---: | :--- |
| **Picar Código Operativo y Scripts** | **Gemini 3.8 Flash** | `Medium` | El caballo de batalla. Cero latencia cognitiva. |
| **Enjambres y Exploración Masiva** | **Gemini 3.8 Flash** | `Low` / `Medium` | Alto throughput en Ring-2. Exige validación *lazy* posterior. |
| **Scripts Complejos sin Cuello de Botella** | **Gemini 3.8 Flash** | `High` | "Flash hipervitaminado": obliga a repasar la lógica antes de ejecutar. |
| **Refactor Masivo e Ingeniería Pura** | **Claude Sonnet 4.6** | `Thinking` | **El Ingeniero Arquitecto**. Seguimiento estricto de tipos, grafos de dependencias e interfaces. |
| **Auditoría Epistémica y Fact-Checking** | **Gemini 3.1 Pro** | `High` | **El Horno Epistémico**. Minimiza la trampa del *cheap talk*. Para diseño teórico y falsación popperiana profunda. |
| **Demostración Lógica y Teoremas** | **Claude Opus 4.6** | `Thinking` | **El Filósofo**. Solo uso quirúrgico (alto consumo de cuota / Rate Limits). |
| **Control de Regresiones (Rollback)** | **Gemini 3.7 / 3.6 Flash** | `Medium` | Uso exclusivo de reserva histórica para verificar si una regresión de comportamiento es culpa de la v3.8. |
| **Neutralidad de Proveedor** | **GPT-OSS 120B** | `Medium` | Auditoría externa desacoplada de filtros de alineación propietarios. |

## 3. Calibración de Regímenes Térmicos (Thinking Levels)

* **`Low` (Inferencia Directa):** Restringido a comandos de terminal, formateo, linting mecánico. Prohibido para resolver contradicciones epistémicas.
* **`Medium` (Equilibrio Operativo):** Régimen estándar de desarrollo interactivo.
* **`High` / `Thinking` (Horno Deliberativo):** Obligatorio cuando un error fáctico o arquitectónico cause una falla en cascada en el sistema. Consume cuota térmica y temporal, protegiendo contra el truncamiento estocástico.
